# Project Euler Solutions in Rust

A comprehensive collection of mathematical and algorithmic solutions to Project Euler problems, implemented in Rust as a practical approach to mastering systems programming and algorithm design.

## Overview

This project demonstrates proficiency in Rust programming through solving challenging computational mathematics problems from [Project Euler](https://projecteuler.net/). The implementations showcase clean code design, efficient algorithms, and mathematical problem-solving skills.

## Technical Highlights

### Problems Solved
- **Problem 1**: Multiples of 3 or 5 - Array iteration and conditional logic
- **Problem 2**: Even Fibonacci Numbers - Dynamic programming and sequence generation
- **Problem 3**: Largest Prime Factor - Prime factorization and number theory
- **Problem 4**: Largest Palindrome Product - String manipulation and nested iteration
- **Problem 5**: Smallest Multiple - Divisibility algorithms and optimization
- **Problem 51**: Prime Digit Replacements - Recursive pattern matching with wildcards

### Key Implementations

**Utility Functions Module** (`useful_functions.rs`):
- **Sieve of Eratosthenes**: Efficient prime number generation algorithm with O(n log log n) complexity
- **Prime Checking Function**: Optimized primality testing with trial division up to √n
- Modular code architecture demonstrating Rust's module system

### Skills Demonstrated
- **Rust Programming**: Ownership, borrowing, pattern matching, and type safety
- **Algorithm Design**: Dynamic programming, recursion, and mathematical optimization
- **Problem Solving**: Breaking down complex mathematical problems into efficient computational solutions
- **Code Organization**: Clean separation of concerns with reusable utility functions
- **Mathematical Foundations**: Number theory, prime numbers, sequences, and combinatorics

## Technical Stack
- **Language**: Rust (2021 Edition)
- **Build Tool**: Cargo
- **Paradigm**: Functional and imperative programming patterns

## Learning Outcomes

This project served as a practical vehicle for:
- Transitioning to Rust from other programming languages
- Understanding Rust's memory safety guarantees without garbage collection
- Implementing classic computer science algorithms in a systems programming language
- Developing efficient solutions to computationally intensive problems
